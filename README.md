# My_Finance

# GETTING STARTED
To get the project on your device, you need to clone the repository. To do this, you need to run the command in the terminal:
```https://github.com/shahzaibahmad020726/MyFinance.git```
Then to get all the dependencies in there, you need to run the command:
```flutter pub get```
After that, you can run the project on your device using the command:
```flutter run```

# FEATURES EXPLANATION
The project is a finance management application. The main features of the application are:
- Adding a new transaction
- Viewing all transactions
- Deleting a transaction
- Adding a new category
- Viewing all categories
- Deleting a category
- A Dashboard with the total balance, total income, and total expense.

# NAVIGATION EXPLANATION
- The application starts with a login screen. If the user is not logged in, the user will be redirected to the login screen.
- The application have 2 icons at the very right of the appbar of HomePage: Categories, SignOut.
- There is a floating action button at the bottom right of the screen to add a new transaction.
